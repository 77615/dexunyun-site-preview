规范说明

德迅云安全官网与控制台改版的统一设计语言。内容与线上「德迅云设计规范」一致。

德迅云安全官网与控制台改版的统一设计语言。以 Arco Design 为组件基础，主色 #165DFF，风格对标火山引擎、腾讯云：克制、留白充足、用数据说话。官网和控制台共用这一套令牌，Figma 中按此建立颜色、文字和效果样式。

版本 1，2026-10-21。基于现官网与控制台的分析整理，Logo 取自现官网。Arco 不完善的组件参考 Arco Pro、Ant Design ProTable、TDesign 补充，补充时只换外观不换令牌。

面向谁

  • 政企客户：看重资质、合规（等保）、服务保障。页面要稳重、可信，信息完整。
  • 中小企业与游戏客户：看重价格、试用、上手速度。页面要直接给出套餐、价格（目前写“价格面谈”）和行动按钮。

官网首屏用两个按钮分流：“免费试用”（主按钮，中小企业）和“联系专家”（次按钮，政企）。

文案原则

  • 用具体数字代替形容词：写“5 秒发现恶意请求，10 秒阻断攻击”，不写“强大”“领先”。
  • 语气专业、平实。不用“轻松躺着过”“无视任何攻击”这类口语或绝对化表达，政企客户会因此降低信任。
  • 产品名首次出现写全称加英文缩写，如“安全加速 SCDN”；中英文之间加空格。
  • 按钮用动词开头：立即咨询、创建实例、查看详情。
  • 空状态要说明下一步：写“还没有接入域名，点击‘添加域名’开始”，不只写“暂无数据”。

颜色

  • 主色 primary-6（#165DFF）：主按钮、链接、选中、焦点环。一个视图里大面积使用的主色不超过一处。
  • Logo 色 brand-navy（#034099）：只属于 Logo，不用于界面控件。
  • 中性色：控制台页面底 bg-2，卡片 bg-1，表头 bg-3；文字 text-1 / text-2 / text-3，text-4 只用于占位和禁用。
  • 语义色：成功 success-6、警告 warning-6、危险 danger-6，只表达状态，不做装饰。语义色作文字时对比度不足，状态标签一律“浅底 + 圆点 + 深色文字”。
  • 图表色：chart-1 到 chart-5 依次取用；0 值或无数据用 chart-empty。
  • 两套主题：浅色为默认，深色用于控制台的深色模式和官网态势大屏类页面。

布局与间距

  • 4px 栅格，间距只取 space-* 令牌。
  • 官网：设计稿 1440 宽，内容区 1200 居中，12 栏，栏间距 24。区块上下间距 space-20（80px），标题到内容 space-12。移动端 375 宽，左右边距 16，单栏。
  • 控制台：设计稿 1440 宽。顶栏 56 高；左侧导航常驻，展开 220、收起 48；内容区边距 space-6，卡片之间 space-4。
  • 圆角：标签 2，按钮和输入框 4，卡片和弹窗 8。
  • 卡片默认只描边（border-1），悬停才加 shadow-1；弹窗、下拉用 shadow-2/shadow-3。

控制台交互规则

这几条直接对应客户反馈的“卡顿、难用”：

  • 导航常驻：左侧二级菜单默认展开，顶部提供产品切换和常用产品收藏，不再把全局菜单藏在抽屉里。
  • 每个子页面有独立网址，刷新、收藏、分享都能回到原页面（设计稿中标注给研发）。
  • 分块加载：每张卡片、每个表格各自显示骨架屏，先到先显示，不整页 loading。
  • 操作即时反馈：提交后按钮立即进入加载态，完成后轻提示“已保存”。
  • 0 值和空状态统一：0 值不染色，图表用灰色底环，空表格给出下一步操作。
  • 列表页顶部只有一个主按钮，其余动作用次按钮或收进“更多”。

图标与图形

  • 界面图标用 Arco Icon 线性风格，16px 为主，与文字同色。
  • 官网插画从现在的 2.5D 等轴插画改为抽象几何、光效和产品界面截图，主色系 primary-3 到 primary-8。
  • 现官网的客户 Logo 墙保留，统一为灰度或单色、等高展示。

Logo

使用现有 Logo（见“Logos”资产组），不改形。浅色背景用原色，深色背景（页脚、surface-deep、深色主题）需要白色反白版，现官网页脚已有，需从设计源文件取用。

控制台组件（kc-*）

控制台原型的所有页面共用 components/bundle.css 这一份样式（前面一小段 dx-* 是官网基础组件，后面是控制台），组件名以 kc- 开头（提示条 ac-al、下拉面板 dd-*、弹窗和轻提示 lp-* 是同一套里的历史命名）。各组件的结构和用法见「控制台 ·」开头的组件卡片。

  • 颜色写成 var(--令牌名, 兜底值)。在本页改令牌后同步到画布，所有控制台页面一起变；括号里的兜底值只在令牌缺失时生效。
  • 控制台用火山风格的一组颜色：主色 kc-primary（#1664FF），文字 kc-text-1 / kc-text-2 / kc-text-3，页面底 kc-bg，状态文字 kc-danger-text / kc-warning-text / kc-success-text。官网用 primary-6（#165DFF）这一组，两组主色目前差一点点，统一与否待定。
  • 页面里不要再写一份公共组件样式。页面自己的少量样式写在页面里，放在 console.css 之后，同名规则以页面为准。
  • 尺寸也有令牌：按钮高度 kc-btn-h / kc-btn-h-sm、按钮内边距 kc-btn-px、输入框高度 kc-input-h、标签高度 kc-tag-h、页签高度 kc-tab-h（「Size」分组），圆角 kc-control-radius、kc-tag-radius、kc-card-radius（「Radius」分组）。
  • 改颜色、尺寸、圆角：改令牌。其它外观（描边、阴影、字重等）：改 components/bundle.css 里对应的规则。改完说「同步组件库」，画布里的副本才会更新。
  • 火山式细节（2026-11-05）：顶栏 Logo 文字显示当前中心名（费用中心、SCDN 等），悬停换成「德迅云控制台」，结构为 .kc-logo > .kc-ln > .kc-ln-c / .kc-ln-b；筛选区下拉 kc-dd 的第一个 span 是固定前缀，带分隔线；页面一级页签 ia-tabs 为卡片式，选中白底加顶部蓝条。

控制台 · 基础

KcBadge数量与风险等级：kc-cnt、kc-lv3
防护功能5/7 待处理12
紧急未受保护可疑已解决

两个小部件：

  • 数量 kc-cnt：跟在标题或页签后面的数字，灰底胶囊。需要警示时加 .r（红字）。放在页签里时自动变成纯数字。
  • 风险等级 i.kc-lv3：8px 圆点放在文字前，r 紧急、o 未受保护、y 可疑、g 已解决。圆点后面必须跟等级文字。
KcButton按钮：主按钮、次按钮、小号、危险、禁用
查看详情

控制台按钮统一用 kc-btn。一个页面只放一个主按钮 kc-btn pri，其余用次按钮或文字链接。

  • kc-btn pri：主操作（创建、保存、立即检测）。
  • kc-btn：次操作（设置、导出、取消）。
  • kc-btn sm：放在提示条、表格行里的小按钮。
  • kc-btn lp-danger：只用在确认弹窗里的危险操作（卸载、删除、重装）。
  • 禁用写 disabled 属性或 .dis 类。
  • 表格操作列、卡片右上角的动作用文字链接，不用按钮。
KcTag状态标签：正常 / 警告 / 危险 / 信息 / 中性
运行中即将到期有风险主账号已停用

状态标签 kc-tag 加一个状态类：ok 正常、warn 警告、err 危险、info 信息、mut 中性。描边加同色文字，透明底。

  • 只表达状态，不做装饰；文字 2 到 5 个字，不加标点。
  • 状态由文字说清楚，颜色只做辅助，不能只靠颜色。
  • 表格的状态列直接放 kc-tag，不要再包圆点或图标。

  • 数量写成 <span class="kc-cnt">，需要警示时加 .r。

控制台 · 表单

KcInput输入框与搜索：kc-in

单行输入和搜索框统一用 input.kc-in，灰底无描边，聚焦时出现主色描边。宽度在使用处指定。

  • 搜索框占位写清能搜什么：「搜索服务器名称、IP 或 ID」。
  • 输入框一定要有 aria-label 或可见标签。
KcSelect下拉选择：kc-dd + dd-w + dd-p（展开态）

官网 · 基础

Button主 / 次 / 文字 / 危险 / 禁用

按钮分主、次、文字、危险四种，一个区域只放一个主按钮。

  • 主按钮（dx-btn--primary）：页面或卡片里最重要的一个动作，如“立即购买”“创建”。现控制台列表页顶部“通用流量 / 维护QQ / 投诉与建议”与“创建”同为蓝色实心，改版后只有“创建”用主按钮，其余用次按钮或收进“更多”。
  • 次按钮（dx-btn--secondary）：并列的其他动作。
  • 文字按钮（dx-btn--text）：表格操作列、卡片底部的“查看详情”。
  • 危险按钮（dx-btn--danger）：删除、释放实例等不可撤销操作，点击后必须二次确认。
  • 大号（dx-btn--large，40px 高）：只用于官网首屏和 CTA 区块。官网首屏固定为“免费试用”（主）+“联系专家”（次），分别面向中小企业和政企。

尺寸：默认 32px 高，左右内边距 space-4，圆角 radius-medium。禁用态用 bg-3 底 + text-4 字。 文案用动词开头，2~4 个字，写清楚会发生什么。
