点链接之后

  1. 1
    点短信或站内信里的链接短链带服务器 ID + 风险 ID
  2. 2
    没登录就先登录登录后自动回到原链接，不落到首页
  3. 3
    打开服务器详情 · 安全页签顶部提示「你从短信链接进入」，对应风险已展开
  4. 4
    按大白话步骤处理异常登录：是我本人 / 不是我；漏洞和弱口令：我已修复，重新检测；也可以选原因忽略
  5. 5
    复检通过才关闭不通过写明原因，留在「未解决」

落地页统一是「服务器详情 · 安全」页签，不是安全卫士里的告警详情，因为收短信的多是只租了服务器的客户。安全卫士用户点站内信时也走同一个落地页，页内有「在德迅安全卫士查看」入口。

字段规则

字段规则
签名【德迅云】，计入字数
等级紧急 / 高危，放在签名后第一个词
服务器名优先用客户备注名，没有就用主机名；超过 16 字截断为前 15 字 + …
风险标题大白话标题（RK-01），不出现 CVE 编号和英文术语，产品名可以保留
直达链接短链，7 天有效；带服务器 ID 和风险 ID。未登录先登录，登录后回到原链接；刷新后仍停在这条风险（NT-07）
退订「回T退订」只关短信；站内信和待办照常（NT-09，开关在通知设置）
字数单条 70 字以内（含签名），超过按 67 字一条拆分计费；紧急和高危必须 1 条以内
接收人资产负责人 + 主账号；服务器转移后只发新归属（NT-01）
