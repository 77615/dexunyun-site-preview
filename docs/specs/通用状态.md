# 通用状态与订阅到期

- 最后更新：2026-11-24（变更 20261124-全流程补齐，决策 #15）
- 画板：账号与费用画布 E1uu「通用状态与订阅到期规范」StateSpec（https://claude.ai/artifact/E1uuQ8QtSKdrmFcHHxSRR9#artboard-StateSpec）；仓库 `console/StateSpec.dc.html`
- 适用：官网会员页、控制台全部产品、账号与费用
- 原则：每个状态只定义一次，做成组件；页面只说「用哪种」，不重新画

## 1. 首次加载

| 规则 | 说明 |
| --- | --- |
| 卡片级骨架屏 | 每张卡片、表格各自显示骨架，先到先显示；不用整页遮罩（LoadSpec 第 2 条） |
| 300 ms 内返回不显示骨架 | 避免闪一下 |
| 表格翻页、筛选 | 只在表格区域显示加载，保留表头和筛选条 |
| 超过 10 秒 | 骨架下方加一行「数据较多，正在加载」，不中断 |

## 2. 空状态

| 类型 | 触发 | 文案示例 | 按钮 |
| --- | --- | --- | --- |
| 从没用过 | 该对象数量为 0 | 「还没有接入的主机」+ 一句这里能做什么 | 主操作（安装客户端 / 添加域名 / 去购买） |
| 筛选无结果 | 有数据但筛选后为 0 | 「没有符合条件的记录」 | 清空筛选 |
| 时间范围无数据 | 图表、日志 | 「这段时间没有攻击」（安全类用正面表述） | 换时间范围 |
| 未开通产品 | 进入未购买产品的控制台 | 产品介绍 + 价格起点（已有 ScdnUnopened 可作为模板） | 去购买 / 免费试用 |

## 3. 加载失败

| 规则 | 说明 |
| --- | --- |
| 卡片内报错 | 「加载失败」+「重试」，其他卡片照常；不弹窗、不整页报错 |
| 连续 3 次失败 | 加「仍然失败？提交工单」，工单自动带页面地址和请求编号 |
| 整页数据都失败（如接口 5xx） | 页面级提示条「服务暂时不可用，正在恢复」+ 重试；菜单和页头照常 |
| 404（资源不存在 / 已释放） | 「这个实例不存在或已释放」+ 返回列表 |

## 4. 操作反馈

| 场景 | 表现 |
| --- | --- |
| 提交中 | 按钮 loading 并禁用，防重复提交；超过 3 秒显示「正在处理」 |
| 成功 | Toast 3 秒，写结果（「已续费 3 个实例」），不写「操作成功」 |
| 失败 | Toast 不自动消失，写原因 + 下一步（每个错误码都要有对应中文，如「该实例有待付款订单，请先付款」） |
| 批量操作部分失败 | 结果弹窗：成功 N、失败 M，失败的逐条列原因，可「重试失败项」 |
| 异步任务（重装、安装客户端、扫描） | 立即返回「已提交」，进度在任务记录里看，完成后站内信 |
| 危险操作 | 二次确认弹窗写后果；不可恢复的要输入名称或验证码（沿用 IdcReinstall） |

## 5. 登录与网络

| 场景 | 表现 |
| --- | --- |
| 登录过期 | 弹窗重新登录（不跳走），登录后停在原页面，未提交表单保留 |
| 在别处登录被踢 | 弹窗说明「账号在其他设备登录」+ 重新登录 + 修改密码 |
| 网络断开 | 顶部条「网络连接已断开」，恢复后自动消失并刷新当前卡片 |

## 6. 没有权限

以 OrgRoles 对照表（5 个角色 × 10 项操作）和卫士三档权限为准。

| 情况 | 表现 |
| --- | --- |
| 整个产品 / 中心没有权限 | 菜单不显示；直接打开链接进 NoAccess：写需要的角色、本企业管理员是谁、「申请权限」（站内信给管理员） |
| 能看不能改 | 页面照常，操作按钮置灰，悬停「需要运维工程师或管理员权限」 |
| 金额只读 | 金额照常显示；付款、申请发票、下单按钮置灰 |
| 使用中权限被改 | 下一次请求返回无权限时提示「你的权限已变更」，刷新当前页 |
| 接口返回无权限但按钮没置灰 | 按「操作失败」处理，Toast 写需要的角色 |

## 8. 订阅到期（德迅安全卫士以外的包月 / 包年产品）

| 阶段 | 状态文案 | 规则 |
| --- | --- | --- |
| 到期前 30 天起 | 即将到期 · 剩 N 天 | 到期前 30 / 7 / 1 天站内信 + 短信，发主账号和该产品的运维工程师；可续费、升配 |
| 到期日 → 第 7 天 | 已到期 · 保留至 X | 只能续费，不能升配、不能改配置；服务降级（下表）；续费核验到账后恢复；保留期内提交了汇款信息，顺延到核验结束，最多 5 个工作日 |
| 保留期结束 | 已释放 | 资源回收、配置删除；列表保留 30 天只读记录后消失；要再用只能新购 |
| 任何时候 | 到期不续 | 「我的产品」卡片「更多」里开关，不发续费提醒，可撤销 |

| 产品 | 保留期内 | 释放后 |
| --- | --- | --- |
| DDoS 高防 IP | 转发不断，防护降到基础防护（超出的攻击可能触发黑洞）；不能改转发规则 | 高防 IP 回收，业务需提前切回源站 IP |
| 游戏盾 | 已接入的连接继续转发，防护降级；不能新增接入 | 接入配置删除 |
| SCDN | 前 3 天照常加速和防护，之后 CNAME 指回源站，网站不中断 | 域名配置删除，可重新添加 |
| 德迅云眼 | 停止新的监测任务，已有报告可以看 | 资产和报告保留 30 天后删除 |
| 服务器 | 到期停机，数据盘保留 | 释放，数据删除 |
| SSL 证书 | 证书按签发有效期失效，与订阅无关；到期前 30 天提醒重新签发 | — |
| 德迅安全卫士 | 不用本规则，见 `德迅安全卫士-授权.md`（宽限期 7 天照常检测） | — |

各产品保留期内的具体表现**待研发确认**。术语：卫士叫「宽限期」（服务照常），其他产品叫「保留期」（服务降级或停止），不混用。

原型示例：AcctSubs「保留期」「已释放」页签（高防-005、SCDN-002、web-old-01、云眼-002、backup-01）；DdosInstances「已到期」筛选（高防-005）。

## 9. 按规格购买的产品下单

- 官网 DDoS 高防 IP / 游戏盾 / SSL 证书规格卡「立即购买」→ `console/AcctPurchase.dc.html?p=ddos|game|ssl&v=<规格序号>`，选购页只显示这一个产品，不出现产品下拉。
- 可改：同产品内的规格、购买时长（DDoS / 游戏盾 1 / 3 / 6 个月、1 年；SSL 1–3 年）、数量；价格取官网公开价，没有公开价的规格（DDoS 全力防护、游戏盾增强版）按钮变「咨询专家」→ Contact。
- 下单前需个人实名；对公转账；核验到账后开通：订单「开通中」→ 实例「待接入」（DDoS 配转发规则、游戏盾接入 SDK、SSL 完成域名验证）→ 运行中；开通失败提示提交工单。
- 不带 `p` 参数时仍是卫士授权选购（见卫士授权 spec）。
