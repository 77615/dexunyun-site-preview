用户与核心任务

企业管理员、运维和财务人员进入首页，先判断需要处理的风险、服务到期与付款事项，再进入对应对象。

信息优先级

  • P0　安全风险与待处理事项
  • P1　产品状态、企业身份和费用摘要
  • P2　快捷访问、企业管理与公告

模块说明

  1. 1

    账户与企业身份

    核对当前账号、企业身份与认证提示。摘要数字为原型演示数据，不能用于判断实际账户状态。

  2. 2

    我的资源

    按产品查看规模及异常状态，再进入对应产品。正式用户中心名称以 V1.2 基线的「我的产品 / 订阅与资源」为准；当前页面名称属于待对齐项。

  3. 3

    安全中心

    先查看紧急风险，再进入对应产品进行分析和处置。打开详情、关闭抽屉或完成操作不代表风险已解决；处置结果需要独立确认。

  4. 4

    其他待办

    核对到期、付款等待办的对象与目标入口。正式基线要求统一「待处理事件」摘要，当前分区方式记录为待对齐项，不在本次标注接入中重构。

  5. 5

    费用信息

    付款、订单和交付状态应分别表达。V1 付款方式为对公转账，核验未匹配时补充汇款信息，避免重复转账。首页余额展示属于已确认的演示例外，不能视为真实交易能力。

  6. 6

    企业

    成员管理回答谁在企业中，角色权限回答能做什么。真实权限、跨企业隔离和操作校验仍需单独验收。

  7. 7

    公告

    公告为辅助信息。通知统一从顶栏铃铛进入；当前公告「更多」的落点与通知关系需要评审确认。

验收边界

数字、日期和状态沿用线上快照，不与真实接口同步。真实付款、交付、安全处置及权限不能按页面可点击认定完成。现有命名、分区及目标链接与正式基线的差异需要另行评审。
