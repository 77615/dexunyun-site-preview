# 德迅安全卫士 · 授权

依据：决策 #10（2026-11-19，老板口述 + 77 确认）；#12–#13（2026-11-23，授权生命周期，见 docs/changes/20261120-卫士授权生命周期）

## 规则
- 不分版本：所有功能（含 AI 研判、威胁狩猎）对每个账号开放。
- 每个账号免费 3 台，注册即发，不需要实名，长期有效；超出按台在线购买（按年，价格待定），付款方式对公转账，到账后生效。买授权、续费、付款需要实名。
- 授权只数台数：不绑 IP、不绑设备、不做激活。
- 用满后新主机无法加入：客户端装好也不会加入，在接入记录里显示「没能加入 · 授权已用满」，资产列表里是「未受保护 · 授权已用满」。
- 已卸载、离线、接入中的主机都算「已用」；只有删除和离线 15 天自动移出才释放名额。
- 换机器：在资产列表删除旧主机，立即释放 1 个名额；删除 = 停用该客户端，重新安装才会再接入。有空余名额后，等待中的主机按尝试接入时间先后自动加入。
- 离线 15 天被自动移出的主机不停用客户端，重新上线后排队加入。
- 离线超过 15 天的主机自动移出列表并释放授权（设置项，默认开）。
- 德迅云服务器随服务器赠送，默认自动安装，不占授权台数。
- 已购授权到期：宽限 7 天（检测告警照常、自动处置暂停）。宽限期内提交了汇款信息，顺延到核验结束，最多 5 个工作日。宽限期内不再接入新主机，也不能扩容，只能续费。
- 台数变少（宽限结束、退款、续费减台数）：主机不移出列表，按最后接入时间倒序，超出的主机变为「未受保护 · 授权已到期」，停止检测；免费 3 台不受影响。卫士管理可在资产列表更换保留哪几台。
- 停止检测的主机数据保留 30 天，页面写明「数据保留至 X」。宽限期过后要「重新购买」，新授权从到账日起算；到账后先恢复被停主机，再让「没能加入」的主机排队加入。
- 扩容：并入已有授权，按剩余天数折算，所有已购授权同一个到期日；入口只有 AcctPurchase。剩余不足 30 天时先续费再扩容。同一授权同时只允许 1 笔待付款订单。
- 续费可以减少台数，从当前到期日起生效。退款按订单退，退掉该订单的台数。
- 授权不能转给其他账号；德迅服务器过户时赠送的防护随服务器走。
- 通知：到期前 30 / 7 / 1 天、宽限期中，以及宽限期结束有主机被停时（站内信 + 短信，列出被停主机）。

## 术语
| 用 | 不用 |
| --- | --- |
| 授权、授权台数、已用 | 企业版、个人版、基础版、份数 |
| 授权已用满、没能加入 | 未授权、超出授权、未绑定 |
| 授权已到期、停止检测 | 超出的主机不受保护 |
| 核验到账后恢复 | 立即恢复 |
| 扩容（并入现有授权） | 转移权益、插件授权 |
| 随服务器赠送，不占授权 | 绑定、激活 |
