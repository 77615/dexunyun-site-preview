# 德迅安全卫士 · 授权

依据：决策 #10（2026-11-19，老板口述 + 77 确认）

## 规则
- 不分版本：所有功能（含 AI 研判、威胁狩猎）对每个账号开放。
- 每个账号免费 3 台，长期有效；超出按台在线购买（按年，价格待定），付款方式对公转账，到账后生效。
- 授权只数台数：不绑 IP、不绑设备、不做激活。
- 用满后新主机无法加入：客户端装好也不会加入，在接入记录里显示「没能加入 · 授权已用满」，资产列表里是「未受保护 · 授权已用满」。
- 换机器：在资产列表删除旧主机，立即释放 1 个名额；有空余名额后，已装好客户端的主机自动加入。
- 离线超过 15 天的主机自动移出列表并释放授权（设置项，默认开）。
- 德迅云服务器随服务器赠送，默认自动安装，不占授权台数。
- 已购授权到期：宽限 7 天（检测告警照常、自动处置暂停），之后这部分主机停止检测；免费 3 台不受影响。

## 页面
| 页面 | 文件 | 要点 |
| --- | --- | --- |
| 授权管理 | console/SecLicense | 概况 4 格（授权台数 / 已用 / 没能加入 / 宽限期），明细：免费额度、购买授权、随服务器赠送 |
| 安全总览授权卡 | console/SecHome | 授权 57 台 · 免费 3 + 已购 54，购买授权 / 续费 |
| 客户端管理 | console/SecAgent | 安装页用满提示；接入记录「没能加入」 |
| 选购产品 | console/AcctPurchase | 卫士只选购买台数 + 期限，无版本 |
| 官网卫士产品页 | ProductHost #price | 价格与授权 4 格 + 免费注册使用 / 购买更多授权 |

## 术语
| 用 | 不用 |
| --- | --- |
| 授权、授权台数、已用 | 企业版、个人版、基础版、份数 |
| 授权已用满、没能加入 | 未授权、超出授权、未绑定 |
| 随服务器赠送，不占授权 | 绑定、激活 |
