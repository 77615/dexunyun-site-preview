# 德迅安全卫士 · 授权

依据：决策 #10（2026-11-19，老板口述 + 77 确认）；#16（2026-11-27，购买的授权手动绑定）；#12–#14（2026-11-23，授权生命周期，见 docs/changes/20261120-卫士授权生命周期；开发交付包 handoff/guard-license/）

## 规则
- 不分版本：所有功能（含 AI 研判、威胁狩猎）对每个账号开放。
- 每个账号免费 3 台，注册即发，不需要实名，长期有效；超出按台在线购买（按年，价格待定），付款方式对公转账，到账后生效。买授权、续费、付款需要实名。
- 绑定（#16，2026-11-27 起，取代原「只数台数」）：免费 3 台在添加主机时自动绑定；购买的授权要在授权管理「绑定主机」里手动勾选主机，绑定后才开始检测。装好客户端但没绑定的主机显示「未受保护 · 待绑定」。可以解绑，解绑后主机停止检测、空出 1 台授权。不绑 IP、不做激活。
- 没有可用授权（免费已用完、已购全部绑定）时不能添加主机。
- 用满后新主机无法加入：客户端装好也不会加入，在接入记录里显示「没能加入 · 授权已用满」，资产列表里是「未受保护 · 授权已用满」。
- 已卸载、离线、接入中、授权已到期（停止检测）的主机都算「已用」；只有删除、离线 15 天自动移出和停检数据清除（30 天）才释放名额。
- 换机器：在资产列表删除旧主机，立即释放 1 个名额；删除 = 停用该客户端，重新安装才会再接入。有空余名额后，等待中的主机按尝试接入时间先后自动加入。
- 离线 15 天被自动移出的主机不停用客户端，重新上线后排队加入。
- 离线超过 15 天的主机自动移出列表并释放授权（设置项，默认开）。
- 德迅云服务器随服务器赠送，默认自动安装，不占授权台数。
- 已购授权到期：宽限 7 天（检测告警照常、自动处置暂停）。宽限期内提交了汇款信息，顺延到核验结束，最多 5 个工作日。宽限期内不再接入新主机，也不能扩容，只能续费。
- 台数变少（宽限结束、退款、续费减台数）：主机不移出列表，按最后接入时间倒序，超出的主机变为「未受保护 · 授权已到期」，停止检测；免费 3 台不受影响。卫士管理可在资产列表更换保留哪几台。
- 停止检测的主机数据保留 30 天，页面写明「数据保留至 X」。宽限期过后要「重新购买」，新授权从到账日起算；到账后先恢复被停主机，再让「没能加入」的主机排队加入。
- 扩容：并入已有授权，按剩余天数折算，所有已购授权同一个到期日；入口只有 AcctPurchase。剩余天数按核验到账日计算（下单页按当天预估）。剩余不足 30 天时先续费再扩容。同一授权同时只允许 1 笔待付款订单。
- 续费可以减少台数：到期前续费，从当前到期日起生效；宽限期内续费，核验到账即生效。确认订单页应付金额写「¥X + 卫士授权（价格待定）」，直到单价确定。退款按订单退，退掉该订单的台数。
- 授权不能转给其他账号；德迅服务器过户时赠送的防护随服务器走。
- 通知：到期前 30 / 7 / 1 天、宽限期中，以及宽限期结束有主机被停时（站内信 + 短信，列出被停主机）。

## 术语
| 用 | 不用 |
| --- | --- |
| 授权、授权台数、已用 | 企业版、个人版、基础版、份数 |
| 授权已用满、没能加入、待绑定、绑定主机 / 解绑 | 未授权、超出授权 |
| 授权已到期、停止检测 | 超出的主机不受保护 |
| 核验到账后恢复 | 立即恢复 |
| 扩容（并入现有授权） | 转移权益、插件授权 |
| 随服务器赠送，不占授权 | 激活 |

## 选购页状态（AcctPurchase，2026-11-23）
| 状态 | 页面表现 |
| --- | --- |
| 新购 | 选台数 + 服务期限 |
| 扩容 | 只选台数，到期日跟随现有授权，按剩余天数折算 |
| 剩余不足 30 天 / 宽限期内 | 不能下单，引导去续费 |
| 已过宽限期 | 重新购买，从到账日起算；到账后按最早接入顺序恢复被停主机 |
| 已有待付款订单 | 不能再下单，按钮变「去付款」 |
