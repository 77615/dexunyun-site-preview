# 服务器控制台

画布：控制台 · 服务器 https://claude.ai/artifact/N8Yuj4E7xMtsnFAbT8om5A（2026-11-17 从「服务器与德迅安全卫士」画布拆出）

## 范围
服务器租用、弹性云服务器、裸金属服务器合用一个控制台，列表用「类型」列和筛选区分。

## 菜单
- 工作区：服务器列表
- 网络与安全：防护设置、安全组
- 运维：监控报表、操作记录

## 页面清单（正式）
| 页面 | 文件 | 要点 |
| --- | --- | --- |
| 服务器列表 | IdcServers | 类型列 + 筛选；行内续费、重启、重装、报表 |
| 服务器详情 | IdcServerDetail | 谁 → 状态 → 页签（基本信息 / 安全 / 监控与报表 / 操作记录）；安全配置在页头按钮 + 抽屉 |
| 重装系统 | IdcReinstall | 详情页上的弹窗：镜像 → 密码 → 数据盘 → 验证码 + 已备份确认 → 进度 |
| 防护设置 | IdcProtect | 一行状态 + 页签 DDoS 防护 / CC 防护 / IP 黑白名单；当前值 + 修改（弹窗）；黑洞中可提前解封 |
| 安全组 | IdcSecGroup | 入 / 出方向规则，放行规则排在兜底拒绝之前 |
| 监控报表 | IdcMonitor | 按服务器和时间筛选；服务器选择在标题右侧 |
| 操作记录 | IdcLogs | 人工操作 / 系统任务 / 失败，详情抽屉 |
| 短信与站内信规格 | SecSms | 点链接落到服务器详情 · 安全 |

## 规则
- 德迅服务器的安全组只在这里改；德迅安全卫士里只读，带「去服务器控制台修改」。
- 设置页不放数据看板：只留影响决策的状态（防护能力、是否在黑洞），趋势数据去监控报表。
- 会产生费用或影响访问的设置用弹窗确认，写清适用场景和费用；无副作用的用开关。
- 攻击通知在消息设置里改。

## 术语
| 叫法 | 含义 |
| --- | --- |
| 服务器 | 租用 / 弹性云 / 裸金属的统称 |
| 保底防护 | 套餐自带的 DDoS 防护带宽 |
| 弹性防护 | 超过保底后继续清洗，超出部分按天计费 |
| 黑洞 | 超过防护能力后公网 IP 暂停访问 |
