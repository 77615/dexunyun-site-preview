## 已按旧需求定下来的规则（v24 已改进原型）

来源：用户中心 V1.2 基线（ia-baseline、critical-flows、v1.2-p0-corrections）和 PRD_开发交付规格_20261012。

| 规则 | 结论 | 改了哪里 |
| --- | --- | --- |
| 待付款订单 | 不自动取消，不需要时手动取消 | BillPayment |
| 订阅到期保留期 | 所有订阅到期后统一保留 7 天（卫士 11-01 到期，保留到 11-08） | SecLicense 等卫士页面、IdcReinstall |
| 开通时机（D2） | 不预开通，付款核验到账后开通或生效 | DdosInstances、ScdnPlan、BillConfirm |
| 订单可见范围（D6） | 全员可看，付款和开票只有主账号、管理员、财务管理员 | BillOrders |
| 通知配置（D5） | 统一在用户中心「消息 › 提醒设置」；接收人 = 资产负责人 + 主账号；产品里只设触发规则（边界和默认订阅仍待业务确认） | Notifications、SecNotify、DdosAlerts |
| 实名认证 | 新购、续费、付款、接收转移前需实名；未认证先去认证，订单留草稿 | ServerBuy、AcctPurchase、BillPayment、AcctTransfer |
| 退款去向 | 原路退回付款对公账户，不进余额（REF-09） | BillBalance、SupTicketNew |
| 交付失败 | 订单仍为已付款，显示开通失败，款项保留，带订单号提工单 | BillOrders、SupTicketNew |
| 核验超时 | 超过 2 个工作日显示「联系客服」（REF-08） | BillOrders |
| 续费防重复、变更锁 | 有未完成订单时显示「去付款」，不能再续费、扩容、升级 | AcctPurchase（有待付款单状态） |
| 批量续费 | 最多 20 项、统一时长、合成一单，转移中和有未完成订单的排除 | AcctSubs |
| 到期不续 | 只改续费意向；原在已取消的产品详情页，新位置待定 | — |
| 工单 | 未解决须说明；待确认 3 天自动解决，解决 7 天后自动关闭；关闭后再次提交复制原内容 | SupTicketDetail、SupTicketNew |
