## 已按旧需求定下来的规则（v23 已改进原型）

来源：用户中心 V1.2 基线（ia-baseline、critical-flows）和基础安全服务蓝图 V1.5。

| 规则 | 结论 | 改了哪里 |
| --- | --- | --- |
| 待付款订单 | 不自动取消，不需要时手动取消 | BillPayment |
| 订阅到期保留期 | 所有订阅到期后统一保留 7 天（卫士 11-01 到期，保留到 11-08） | SecLicense 等卫士页面、IdcReinstall |
| 开通时机（D2） | 不预开通，付款核验到账后开通或生效 | DdosInstances、ScdnPlan、BillConfirm、AcctUsage |
| 订单可见范围（D6） | 全员可看，付款和开票只有主账号、管理员、财务管理员 | BillOrders |
| 通知配置（D5） | 统一在用户中心「消息 › 提醒设置」；接收人 = 资产负责人 + 主账号；产品里只设触发规则 | Notifications、SecNotify、DdosAlerts |
| 转移影响（R4） | 告警只通知接收方，旧风险转移归档，证据留原账号，确认后全量检测 | AcctTransferDetail |
| 告警转工单（R6） | 风险详情「提交安全工单」，自动带风险和证据，结果回填、复检通过才结案 | SecRiskDetail、SupTicketNew |
| 实名认证 | 新购、续费、付款、接收转移前需实名；未认证先去认证，订单留草稿 | ServerBuy |
