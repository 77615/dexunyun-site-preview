# 卫士研发同步会规则（2026-11-27）

来源：研发同步会纪要 https://claude.ai/artifact/Y88Na4L2bGc1Br6ZqeUSjY ；77「可以先根据这个修改原型」。

| 规则 | 改了哪里 |
| --- | --- |
| 只连端口未登录算暴力破解；输错密码算异常登录，同一来源合并并显示次数；登录成功不提醒 | 登录安全防护：新增系统规则「密码错误登录」、功能说明、标准模式说明；告警中心示例改为「输错密码 312 次（已合并为 1 条）」 |
| 弱口令默认检测、只告警，不强制改密码、不禁止登录；关闭检测和忽略告警都记操作人 | 登录安全防护：系统规则「弱口令检测」、变更记录示例；告警中心新增待研判 / 已忽略两条弱口令告警（忽略人写在忽略原因里）；侧栏告警中心数字 6 → 7 |
| 病毒扫描分慢 / 正常 / 快，默认慢；快档按配置最多约 50% CPU；快速扫描最长 1 小时 | 病毒查杀：查杀栏加「扫描速度」，副标题显示当前速度；扫描任务加「速度」列和表单项 |
| 外联管控：标准阻断高危 IP，重保阻断全部海外；情报库自动更新并记录 | 网络访问防护：三种模式说明、外联规则「高危 IP 阻断」「重保：阻断全部海外连接」、变更记录里系统的情报库更新 |
| 高危命令上线时显示「敬请期待」，不隐藏 | 全部 30 页侧栏「高危命令」带「敬请期待」；高危命令页默认显示敬请期待，可切到后续版本设计；应用运行防护检测项一行显示敬请期待 |
| 主机过户：配置和告警记录跟着走，操作记录不转；先暂停运行中的任务，漏洞扫描要等扫完 | 资产列表：行「更多」加「过户到其他账号」抽屉（接收账号、数据范围、运行中任务、授权说明，对方 24 小时内确认） |

授权绑定（77 决策卡选「改：购买的手动绑定」，决策 #16）：授权管理加演示切换「宽限期 / 正常使用」；正常使用下概况改为已绑定 / 待绑定主机 / 可用授权，购买授权行加「绑定主机」抽屉（勾选等待绑定的主机，已绑定的可解绑）。免费 3 台仍自动绑定。资产列表加原因「待绑定」，操作「绑定授权」跳授权管理。

`scripts/p27.py` 在原页面上打补丁（P27SRC / P27DST 指定输入输出目录），画布 LE5c v380 和仓库 console/ 都用它生成。
