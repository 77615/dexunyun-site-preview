# 变更提案：德迅安全卫士授权改为「三台免费、按台购买」

状态：已确认（2026-11-19，77 选了「德迅服务器不占 3 台免费名额，随服务器赠送」；其余待决策按推荐项先做：按年续费、价格待定、删除即释放、离线 15 天自动释放保留）

## 为什么改
老板定了新的授权口径（F1–F7）：不分企业版和个人版，注册即免费用 3 台；超过 3 台在线买授权，买几台就能多加几台。授权只数台数，不绑 IP、不绑设备、不做激活；用满了新主机就加不进来，换机器就删旧加新。目的是减少「换 IP / 换硬件要改授权」的售后。

## 现状（原型里和新口径冲突的地方）
- **版本**（事实）：官网 ProductHost 有「德迅安全卫士企业版」整块介绍和 4 个功能卡；AcctPurchase 有「企业版 / 个人版（当前）」选择和版本对比弹窗；卫士 31 个页头写「企业版 · 68 台主机」；SecHome 授权卡可切换「企业版 / 基础版」、按钮「升级企业版」；客户端管理里 AI 研判标「企业版」。按 2026-10-30 的口径，两版只差 AI 研判。
- **绑定**（事实）：SecLicense 有「新主机自动绑定授权」开关、「已绑定 64/64」；主机多出授权时状态是「未授权 · 只告警不防护」（app-07），资产列表、总览待办、报表、ConsoleHome 待处理都在引用这个状态，并有「绑定授权」按钮。新口径下不存在「装上了但没授权」的主机：用满了就加不进来。
- **到期**（事实）：示例授权 2025-11-02 至 2026-11-01，现在是「宽限期，数据保留至 11-08」；SecHome、SecLicense、SecNotify（授权到期提醒）、AcctProductDetail 都在讲到期和续费。新口径没说购买的授权是不是按年。（待定）
- **同一概念多叫法**（事实）：授权 / 权益 / 保护范围 / 服务（AcctProductDetail「2 项有效」）/ 授权使用情况（AcctUsage）。
- **德迅服务器**（事实）：官网写「弹性云服务器 赠德迅卫士主机防护」；服务器交付后默认自动装客户端（蓝图 V1.5、决策 #4/#5）。新口径没说德迅服务器占不占 3 台免费名额。（待定，见待决策 1）
- **数据量**（事实）：示例账号 68 台主机、64 个授权。新口径下要改成「3 免费 + 买的」的数，例如 3 + 61 = 64。

## 待决策
1. **德迅云的服务器占不占 3 台免费名额？**（发决策卡）
   - A（推荐）不占：德迅服务器随单送防护、自动装，不算台数；3 台免费和购买授权只管用户自己的其他机器。和官网「赠德迅卫士主机防护」、默认安装流程一致，不会出现「买了第 4 台服务器装不上卫士」。
   - B 占：所有主机一起算，德迅服务器第 4 台起也要买授权；用满时德迅新服务器自动安装会失败。
2. 购买的授权是一次买断还是按年续费？推荐**按年**（保留现有到期提醒和续费页），免费 3 台永久有效。如果是买断，要删掉到期、宽限期、续费相关的所有文案。
3. 单价：官网和购买页先写「待定」，等老板给数。
4. 删除主机后多久能加新主机？推荐**立即释放**，不设冷却期（老板原意是减少售后）。
5. 主机离线很久要不要自动释放授权？现有设置「离线超过 15 天自动移出列表，释放授权」，推荐保留。
