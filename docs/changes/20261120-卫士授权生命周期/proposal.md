# 变更提案：德迅安全卫士授权生命周期（到期、扩容、异常与逆向）

状态：待确认（第 1、2 条 77 已于 2026-11-20 确认；第 8–13 条 77 于 2026-11-23 同意按推荐补入；第 3–7 条按推荐写入，等 77 确认）

## 为什么改
F1：11-19 改成「3 台免费、按台购买」后，主流程是通的，但「台数变少时谁停」「扩容怎么算」等规则没定，原型里还留着旧口径。F2、F3 已定下其中两条。

## 现状（详见分析文档 P1–P11）
- 规则停在旧版本（事实）：AcctProductDetail 概览仍是「授权 52 / 已用 70 / 超出 18 · 超出的主机不受保护」；客户端能力列表仍有「安装插件 / 插件授权」（11-06 已取消插件）；IdcServerDetail 卸载弹窗「释放 1 个授权，可以绑定到其他服务器」（德迅服务器不占授权，也没有绑定）。
- 同一对象多个说法（事实）：同一批 54 台授权，SecLicense 写 11-01 到期宽限中，AcctSubs 写 10-25 到期保留中，AcctProductDetail 写运行中 2027-01-26 到期；另有 dx-guard-02 两台。关联订单 20+10+25=55 ≠ 54，且单价待定却写了金额。
- 同一操作多个入口（事实）：「扩容」→ BillConfirm（续费确认页），「购买授权」→ AcctPurchase。
- 承诺与规则矛盾（事实）：BillConfirm「保留期内续费，防护立即恢复」vs 对公转账 1–2 工作日核验；BillBalance「续费优先从余额扣」vs 付款方式只有对公转账；Register「实名后申请免费试用」vs 官网「注册即送 3 台」。
- 已定未落地（事实）：11-10 批准的逆向修改（开通失败、核验超时、到期不续、申请退款 / 已退款、余额只展示）在 kyno3x 分支 3903f36，未合入 main。

## 新规则
1. **台数变少时（已定，F2）**：已购授权到期且宽限 7 天结束、退款、续费减台数后，主机不移出列表。按最后接入时间倒序，超出授权台数的主机变为「未受保护 · 授权已到期」，停止检测；用户可在资产列表换保留哪几台；续费或购买核验到账后自动恢复。免费 3 台不受影响。
2. **扩容（已定，F3）**：并入已有授权，按剩余天数折算价格，所有已购授权同一个到期日。购买入口只保留 AcctPurchase：没有已购授权时是「新购（选台数 + 期限）」，有时是「扩容（只选台数，到期日跟随现有授权）」。续费页可以改台数（减少后超出部分按第 1 条处理）。
3. 免费 3 台注册即发，不需要实名；买授权、续费、付款仍需个人实名。
4. 名额空出时，等待中的主机按尝试接入时间先后加入；删除主机 = 停用该客户端，重新安装才会再接入。
5. 已卸载、离线、接入中的主机都算「已用」；只有删除和离线 15 天自动移出才释放。
6. 宽限期内提交了汇款信息，宽限顺延到核验结束；文案统一为「核验到账后恢复」。
7. 授权不能单独转给其他账号（V1）；去掉 AcctProductDetail「转移权益」。德迅服务器过户时赠送随服务器走。

8. **名额恢复的顺序**：续费或购买到账后，先恢复「授权已到期」被停的主机，再让「没能加入」的主机按尝试接入时间加入。
9. **临近到期扩容**：剩余不足 30 天时，扩容页提示「先续费再扩容」；宽限期内只能续费，不能扩容。
10. **停止检测后的数据**：被停主机的风险和事件记录保留 30 天（建议值），期间续费可接着用，之后删除；页面写明保留到哪天。
11. **宽限期结束通知**：宽限期结束、有主机被停时，站内信 + 短信通知主账号和卫士管理，列出被停主机。
12. **并入后的退款**：按订单退，退掉该订单买的台数；台数变少后按第 1 条处理。
13. **谁能操作**：「更换保留主机」只有「卫士管理」能做；付款、续费沿用现有规则（主账号 / 管理员 / 财务）。
