# 变更提案：控制台总览改成腾讯式布局

状态：已确认（2026-11-17，老板提出、77 回「可以」；第二轮 F5：77 要求其他账号页一起改，去掉首页标注插件）

## 为什么改
F1、F3：总览页左侧只有 4 个菜单，下面整列留白，页面没有整体感。F2：顶部整排的账号与费用数据太散，要像腾讯云右上账户卡那样收进去。F4：内容不变，只改排版。

## 现状
- 事实：ConsoleHome 有 4 项左侧菜单（总览 / 我的产品 / 费用 / 企业），顶部一整条账号数据（余额、待付款、到期、工单、安全分），右栏首块「费用信息」（待付款、近半年付款柱图、本月已付款、可开票金额）。
- 事实：其他账号页（AcctProducts、Bill*、Org*）同样用这 4 项左侧菜单，本次不动。
- 推断：账号数据和费用信息里「待付款」重复出现过两次，合并后只留一处。

## 改什么
| 动作 | 对象 | 说明 |
| --- | --- | --- |
| 修改 | ConsoleHome 左侧菜单 | 只在总览页去掉；改为欢迎语下方横排页签「总览 / 我的产品 / 费用 / 企业」，分别链到 ConsoleHome / AcctProducts / BillOverview / OrgInfo |
| 修改 | 顶部账号条 + 右栏「费用信息」 | 合并成右上账户卡：身份 → 汇款未匹配提示 → 账户余额 + 充值 + 查订单/收支明细/发票/账务概览 → 待付款 + 去付款/申请开票 + 近半年付款小柱图 → 本月已付款、可开票金额、到期与即将到期、未关闭工单 |
| 修改 | 右栏「企业」 | 成员 / 角色 / 账号安全分改成一行三格，右栏高度和左栏对齐；右栏不再吸顶 |

## 第二轮（F5）
- 账号与费用画布上 37 个带「总览 / 我的产品 / 费用 / 企业」左侧菜单的页面全部去掉左侧菜单，改为顶部一级页签（16px，黑色 2px 下划线），按页面归属高亮：Acct* → 我的产品，Bill* 和 NoAccess → 费用，Org* → 企业，ConsoleHomeNew → 总览；工单、文档、消息、全局搜索等顶栏入口页不高亮。
- 分组页（标题就是「我的产品 / 费用 / 企业」，下面有二级页签）：原标题行换成一级页签，原标题行上的按钮移到页签行右侧；二级页签保留。详情和流程页：一级页签放在原标题上方。
- 总览页页签字号同步改成 16px。
- ConsoleHome 去掉 Axhub 标注插件（两个 script 和 7 个 data-annotation-id）；axhub-annotation.global.js、home-annotations.* 文件留在仓库，需要时可以再挂回去。
- 产品控制台（SCDN、DDoS、卫士等）的左侧菜单不动。

## 第三轮（F6）
- 12 个分组页（AcctProducts、AcctSubs、BillOverview、BillOrders、BillPay、BillBalance、BillInvoice、BillContract、OrgInfo、OrgMembers、OrgRoles、OrgSecurity）加首页同款头部：欢迎语、蓝色渐变背景，一级页签与首页同一位置，切换时头部不动。
- 一级页签行只放页签；原来挂在这一行右侧的页面按钮挪到二级页签行右侧。
- 二级页签改成首页「最近访问」同款胶囊（选中浅蓝底蓝字）。
- 卡片统一首页样式：无边框、直角、0 1px 4px 阴影；左右边距 24 与首页一致。
- 详情和流程页不加欢迎语，保持原标题。

## 第四轮（F7–F13）
- 「我的产品」改成卡片版（参考 Agent Inbox Board）：按状态分三栏「需处理 / 正常运行 / 已结束」，可切换列表视图；卡片网格 minmax(340px,1fr) 自动排列，超宽屏不拉伸（1440 三列、1920 五列、2560 六列）。
- 卡片：产品图标、名称与规格、带图标的状态标签（描边告警 / 警告 / 正常 / 停用图标，不用圆点）、两行说明、用量条、到期时间；底部操作栏直接放续费 / 升级 / 扩容和「进入控制台 ›」，点卡片主体打开右侧详情抽屉。
- 页签分三级：一级顶部下划线页签；二级胶囊页签放在白色容器顶部、和下面的卡片连成一个容器；三级为灰底分段筛选（状态计数用灰字，需关注用红字）。
- 同一层级规则同步到其余 11 个分组页（AcctSubs、Bill* 6 页、Org* 4 页）。
- 首页次级页签的「纸张叠放」切换动效试过后撤回，不采用。

## 第五轮（F14）
- 费用、企业的概览类页面胶囊条下面有多张卡片，胶囊条单独一条白底显得和内容没有关系。改成胶囊条和下面整块内容放在同一个容器里：容器白底细边框，顶部是胶囊条，下面是浅灰内底，内容卡片放在内底上（同「我的产品」卡片版）。

## 第六轮（F15）我的产品语义色
依据腾讯控制台设计文档的语义色三层规则和总览页细节：
- 状态分三档轻重：需立刻处理（攻击中、已到期）用错误浅色标签（#fce8e8 底、#b42c3f 字和图标）；需要关注（即将到期、接近上限）用警告浅色标签（#ffeddf 底、#c04100 字）；只需知晓（运行中、已完成）只放图标和灰字，不加底色。卡片、列表、详情抽屉三处一致。
- 单独出现的状态文字、图标和进度条用 8 阶：错误 #f64041、警告 #ff7800、成功 #0cbf5b；正常用量条用品牌蓝。进度条改直角纯色，轨道 #e6e9ef。
- 产品图标块按分类用三种淡彩：云安全蓝 #e3ecff，主机安全和安全运营薄荷 #d3f4ef，IDC 和安全服务灰 #e5e9f0。
- 文字统一黑色透明度 .9 / .7 / .5，卡片说明、列表、抽屉正文 12/20。
- 卡片悬停只加 md 阴影，不加蓝框；选中才用品牌色描边。需处理的计数用红色数字。
- 77 在画板里直接改过的样式（页签条、卡片区背景、标签直角）原样保留。

## 第七轮（F16）卡片视图分组和操作
- 每个状态分组（需处理 / 正常运行 / 已结束）是一个浅灰 #f5f6f8 容器，分组标题和计数在容器顶部，卡片排在容器里，标题和卡片属于同一块。
- 卡片 4px 圆角、极浅阴影，悬停加阴影。
- 卡片底部不再有灰色底条和分割线：左边「进入控制台 ›」文字链接；右边次要操作是文字按钮（悬停才出现浅灰底），主操作是白底描边小按钮，放在最右。

## 第八轮（F17）参考 Files 页
- 「按产品 / 按资源」从单独一行挪到筛选行右侧，变成分段切换；状态筛选在左侧，改成安静页签（选中浅灰底，未选中无底无框）。容器里只剩一行工具。
- 新增搜索：按产品名、套餐、分类、说明过滤，分组计数跟着变；搜不到时显示空状态和「清除搜索」。
- 新增加载中：灰色占位块和真实卡片同一形状，数据回来不跳动；新增无产品空状态：图标、一句说明、购买产品按钮。
- 底部「原型状态」切换（数据 / 加载中 / 无产品）只用于演示，开发不用实现。
- 按资源页（AcctSubs）顶部同步成同一行：左边状态安静页签，右边按产品 / 按资源分段 + 权益转移、到期提醒设置（第九轮，F18）。

## 第十轮（F19）费用、企业同步
- 二级页签（概览 / 订单 / 付款 / 收支明细 / 发票 / 合同；企业信息 / 成员 / 角色权限 / 安全设置）从胶囊改成分段切换，和「按产品 / 按资源」一样。
- 卡片里的状态页签改成安静页签，和我的产品状态筛选一样；需关注类计数红色。
- 容器去掉描边、用浅阴影。只有一张表格的页（订单、发票、合同）容器内全白，表格并进容器，同按资源页；有多块内容的页（概览、付款、收支明细、企业 4 页）保留浅灰内底，同我的产品卡片视图的分组底。

## 第十一轮（F20）费用页按模块分层
- 内容区白底不变。每个模块的标题挪到模块框外面（13px 灰字，右侧放链接或时间切换），下面是白底、1px #e9ecf1 描边、4px 圆角的模块框，不用阴影；模块之间 24px。
- 模块里的次级面板（可用余额、可开票金额、待办）用浅灰底、无描边，形成「页面 → 模块框 → 灰色面板」三层。
- 待付款、可用余额两个重点模块用淡蓝渐变底。
- 适用于费用概览、收支明细。

## 不改什么

- 顶栏不变。
