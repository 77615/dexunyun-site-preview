# 变更提案：控制台总览改成腾讯式布局

状态：已确认（2026-11-17，老板提出、77 回「可以」；第二轮 F5：77 要求其他账号页一起改，去掉首页标注插件）

## 为什么改
F1、F3：总览页左侧只有 4 个菜单，下面整列留白，页面没有整体感。F2：顶部整排的账号与费用数据太散，要像腾讯云右上账户卡那样收进去。F4：内容不变，只改排版。

## 现状
- 事实：ConsoleHome 有 4 项左侧菜单（总览 / 我的产品 / 费用 / 企业），顶部一整条账号数据（余额、待付款、到期、工单、安全分），右栏首块「费用信息」（待付款、近半年付款柱图、本月已付款、可开票金额）。
- 事实：其他账号页（AcctProducts、Bill*、Org*）同样用这 4 项左侧菜单，本次不动。
- 推断：账号数据和费用信息里「待付款」重复出现过两次，合并后只留一处。

## 改什么
| 动作 | 对象 | 说明 |
| --- | --- | --- |
| 修改 | ConsoleHome 左侧菜单 | 只在总览页去掉；改为欢迎语下方横排页签「总览 / 我的产品 / 费用 / 企业」，分别链到 ConsoleHome / AcctProducts / BillOverview / OrgInfo |
| 修改 | 顶部账号条 + 右栏「费用信息」 | 合并成右上账户卡：身份 → 汇款未匹配提示 → 账户余额 + 充值 + 查订单/收支明细/发票/账务概览 → 待付款 + 去付款/申请开票 + 近半年付款小柱图 → 本月已付款、可开票金额、到期与即将到期、未关闭工单 |
| 修改 | 右栏「企业」 | 成员 / 角色 / 账号安全分改成一行三格，右栏高度和左栏对齐；右栏不再吸顶 |

## 第二轮（F5）
- 账号与费用画布上 37 个带「总览 / 我的产品 / 费用 / 企业」左侧菜单的页面全部去掉左侧菜单，改为顶部一级页签（16px，黑色 2px 下划线），按页面归属高亮：Acct* → 我的产品，Bill* 和 NoAccess → 费用，Org* → 企业，ConsoleHomeNew → 总览；工单、文档、消息、全局搜索等顶栏入口页不高亮。
- 分组页（标题就是「我的产品 / 费用 / 企业」，下面有二级页签）：原标题行换成一级页签，原标题行上的按钮移到页签行右侧；二级页签保留。详情和流程页：一级页签放在原标题上方。
- 总览页页签字号同步改成 16px。
- ConsoleHome 去掉 Axhub 标注插件（两个 script 和 7 个 data-annotation-id）；axhub-annotation.global.js、home-annotations.* 文件留在仓库，需要时可以再挂回去。
- 产品控制台（SCDN、DDoS、卫士等）的左侧菜单不动。

## 不改什么
- 页面上的数据、文案、链接、安全中心和其他待办的交互都不变。
- 顶栏不变。

## 影响面
- 画布：账号与费用 E1uu（v79），ConsoleHome 画板高度 2300 → 1300。
- 菜单：只影响总览页。
- 仓库：console/ConsoleHome.dc.html 保留 Axhub 标注脚本和 7 个 data-annotation-id（home-account、home-fees 移到新账户卡）。docs/specs/控制台总览标注（PR #10）的截图是旧布局，需要重截。
- 组件库：页签样式 .tcl-tabs 暂写在页面里（腾讯规范：40 高、黑色 2px 下划线）；如果推广到其他页再收进组件库。

## 推翻的旧决定
无编号决定。改变的是 2026-10-27 v79「用户中心收成 4 个左侧菜单」在总览页的呈现方式：菜单项不变，位置从左侧移到页签。
