## 2. 提案

每条给出建议做法。标「研发确认」的是需要后端评估可行性的，建议先按这个画原型。

### P1 按规格购买的产品能下单（S1）

| 项 | 建议 |
| --- | --- |
| 入口 | 官网规格卡「立即购买」继续带 `p`、`v` 参数进 AcctPurchase |
| 页面 | AcctPurchase 按 `p` 显示**一个固定产品**（不恢复产品下拉）：规格（同产品内可改）、购买时长（1 / 3 / 6 / 12 个月，长期折扣待定）、数量、付款与票据、协议、提交订单。不带 `p` 时仍是卫士授权 |
| 「面议」规格 | DDoS「全力防护」、游戏盾旗舰型等没有公开价的，按钮变「咨询」→ Contact，带咨询对象 |
| 未登录 | 先登录 / 注册，回来时保留所选规格 |
| 未实名 | 可以填，提交时引导个人实名，订单存为草稿（同卫士 R09） |
| 付款后 | 订单「付款核验中」→ 核验到账 →「开通中」→ 实例出现在产品列表，状态「待接入」（DDoS / 游戏盾要先配转发规则或接入 SDK）→ 配好后「运行中」 |
| 开通失败 | 订单「已付款 · 开通失败」，引导提交工单（已有） |
| 待付款锁 | 同一产品同一规格可以有多笔待付款（新购不锁）；续费 / 升配按实例锁 1 笔（同卫士 R12 思路） |

### P2 订阅产品统一到期规则（S2 S3 S4 S9）

**建议：除卫士外，所有包月 / 包年产品用同一套「保留期 7 天」规则**，每个产品只写「保留期里服务怎么样」。

| 阶段 | 统一规则 |
| --- | --- |
| 到期前 30 / 7 / 1 天 | 站内信 + 短信，发主账号和该产品的运维工程师；列表行显示「N 天后到期」 |
| 到期日 → 保留期第 7 天 | 状态「已到期 · 保留至 X」；只能续费，不能升配、不能改配置；续费核验到账后恢复；保留期内提交汇款信息，顺延到核验结束，最多 5 个工作日（同卫士 R14） |
| 保留期结束 | 状态「已释放」，资源回收，配置删除，列表保留 30 天只读记录后消失；要用只能新购 |
| 到期不续 | 打开后不发续费提醒，到期按上面走（已有） |

每个产品保留期里的服务表现（**研发确认**）：

| 产品 | 保留期内 | 释放后 |
| --- | --- | --- |
| DDoS 高防 IP | 转发不断，防护降到基础防护（超过基础的攻击可能触发黑洞）；不能改转发规则 | 高防 IP 回收，业务需提前切回源站 IP |
| 游戏盾 | 已接入的连接继续转发，防护降级；不能新增接入 | 接入配置删除 |
| SCDN | 域名继续加速和防护 3 天，之后 CNAME 指回源站（不断网站访问） | 域名配置删除，可重新添加 |
| 德迅云眼 | 停止新的监测任务，已有报告可看 | 资产和报告保留 30 天后删除 |
| 服务器 | 停机，数据盘保留 | 释放，数据删除（已有「到期停机」，补规则） |
| SSL 证书 | 证书按签发有效期失效，与订阅无关；到期前 30 天提醒重新签发 | — |
| 德迅安全卫士 | **不变**，按授权规则（宽限期 7 天照常检测，之后超出部分停检） | — |

术语：卫士叫「宽限期」（服务照常），其他产品叫「保留期」（服务降级或停止）。两个词不能混用，写进 spec 术语表。

### P3 全站通用状态（S5）

写一份 `docs/specs/通用状态.md`，原型只加**一张「通用状态」画板**，各页面不逐个画，开发统一做成组件：

- 首次加载：卡片级骨架屏（沿用 LoadSpec）
- 空状态：三种（从没用过 → 引导开通 / 添加；筛选无结果 → 清空筛选；无权限看 → 见 P4）
- 加载失败：卡片内「加载失败 · 重试」，不整页报错；连续 3 次失败给工单入口
- 操作失败：Toast 写原因 + 下一步；批量操作给成功 / 失败明细
- 提交中：按钮 loading，防重复提交
- 登录过期：弹窗重新登录，登录后回到原页面，未提交的表单保留
- 网络断开：顶部条「网络连接已断开」，恢复后自动消失

### P4 产品页里的权限表现（S6 S7）

以 OrgRoles 现有对照表为准，补「在页面上怎么表现」（见 `docs/specs/通用状态.md` 第 6 节）：

| 情况 | 表现 |
| --- | --- |
| 整个产品没有权限（如财务管理员进产品配置） | 菜单里不显示；直接打开链接 → NoAccess，写明需要哪个角色、谁是管理员 |
| 能看不能改（普通成员、运维看金额） | 页面照常显示，操作按钮**置灰**，悬停「需要运维工程师或管理员权限」；不隐藏，免得用户以为没这个功能 |
| 金额只读 | 金额照常显示，付款 / 申请发票按钮置灰 |
| 卫士三档 | 沿用 OrgMemberNew：卫士管理 / 安全运营 / 只读 |
| 角色在使用中被改 | 下一次操作时提示「你的权限已变更」，刷新页面 |

### P5 登录、注册、找回密码报错（S8）

| 页面 | 要补的状态 |
| --- | --- |
| 登录 | 账号或密码错误（不说哪一个错）、连续 5 次错误锁 15 分钟、验证码错误 / 过期、账号已冻结（联系客服） |
| 注册 | 手机号已注册（去登录 / 找回密码）、验证码错误 / 过期、60 秒内重发、密码强度不够、未勾协议 |
| 找回密码 | 手机号未注册、验证码错误、新密码与旧密码相同 |
| 全站 | 登录过期（见 P3） |

### P6 其他（低优先）

- 发票：开票中、已开票、已驳回（已有）、已作废 / 红冲
- 卫士客户端：升级失败、版本过低（已有）后的升级引导

## 3. 给开发的交付格式

每个产品按卫士授权交付包的格式出一份（模板见 `docs/templates/handoff.md`）：规则 R 编号 → 状态图 → 原型改动点 C 编号 → 异常场景 E 编号 → 前端 / 后端 / 数据任务带验收标准。顺序建议：DDoS 高防 IP → 服务器 → 游戏盾 → SCDN → 云眼。
