# 通用状态（草案）

- 状态：草案，77 确认 proposal 后移到 `docs/specs/通用状态.md`
- 适用：官网会员页、控制台全部产品、账号与费用
- 原则：每个状态只定义一次，做成组件；页面只说「用哪种」，不重新画

## 1. 首次加载

| 规则 | 说明 |
| --- | --- |
| 卡片级骨架屏 | 每张卡片、表格各自显示骨架，先到先显示；不用整页遮罩（LoadSpec 第 2 条） |
| 300 ms 内返回不显示骨架 | 避免闪一下 |
| 表格翻页、筛选 | 只在表格区域显示加载，保留表头和筛选条 |
| 超过 10 秒 | 骨架下方加一行「数据较多，正在加载」，不中断 |

## 2. 空状态

| 类型 | 触发 | 文案示例 | 按钮 |
| --- | --- | --- | --- |
| 从没用过 | 该对象数量为 0 | 「还没有接入的主机」+ 一句这里能做什么 | 主操作（安装客户端 / 添加域名 / 去购买） |
| 筛选无结果 | 有数据但筛选后为 0 | 「没有符合条件的记录」 | 清空筛选 |
| 时间范围无数据 | 图表、日志 | 「这段时间没有攻击」（安全类用正面表述） | 换时间范围 |
| 未开通产品 | 进入未购买产品的控制台 | 产品介绍 + 价格起点（已有 ScdnUnopened 可作为模板） | 去购买 / 免费试用 |

## 3. 加载失败

| 规则 | 说明 |
| --- | --- |
| 卡片内报错 | 「加载失败」+「重试」，其他卡片照常；不弹窗、不整页报错 |
| 连续 3 次失败 | 加「仍然失败？提交工单」，工单自动带页面地址和请求编号 |
| 整页数据都失败（如接口 5xx） | 页面级提示条「服务暂时不可用，正在恢复」+ 重试；菜单和页头照常 |
| 404（资源不存在 / 已释放） | 「这个实例不存在或已释放」+ 返回列表 |

## 4. 操作反馈

| 场景 | 表现 |
| --- | --- |
| 提交中 | 按钮 loading 并禁用，防重复提交；超过 3 秒显示「正在处理」 |
| 成功 | Toast 3 秒，写结果（「已续费 3 个实例」），不写「操作成功」 |
| 失败 | Toast 不自动消失，写原因 + 下一步（每个错误码都要有对应中文，如「该实例有待付款订单，请先付款」） |
| 批量操作部分失败 | 结果弹窗：成功 N、失败 M，失败的逐条列原因，可「重试失败项」 |
| 异步任务（重装、安装客户端、扫描） | 立即返回「已提交」，进度在任务记录里看，完成后站内信 |
| 危险操作 | 二次确认弹窗写后果；不可恢复的要输入名称或验证码（沿用 IdcReinstall） |

## 5. 登录与网络

| 场景 | 表现 |
| --- | --- |
| 登录过期 | 弹窗重新登录（不跳走），登录后停在原页面，未提交表单保留 |
| 在别处登录被踢 | 弹窗说明「账号在其他设备登录」+ 重新登录 + 修改密码 |
| 网络断开 | 顶部条「网络连接已断开」，恢复后自动消失并刷新当前卡片 |

## 6. 没有权限

以 OrgRoles 对照表（5 个角色 × 10 项操作）和卫士三档权限为准。

| 情况 | 表现 |
| --- | --- |
| 整个产品 / 中心没有权限 | 菜单不显示；直接打开链接进 NoAccess：写需要的角色、本企业管理员是谁、「申请权限」（站内信给管理员） |
| 能看不能改 | 页面照常，操作按钮置灰，悬停「需要运维工程师或管理员权限」 |
| 金额只读 | 金额照常显示；付款、申请发票、下单按钮置灰 |
| 使用中权限被改 | 下一次请求返回无权限时提示「你的权限已变更」，刷新当前页 |
| 接口返回无权限但按钮没置灰 | 按「操作失败」处理，Toast 写需要的角色 |

## 7. 开发对照

| 组件 | 现有画板 | 状态 |
| --- | --- | --- |
| 骨架屏 | LoadSpec | 已有规范 |
| 空状态 | ScdnUnopened（未开通）、Sec* 各页 | 已有，需统一 |
| 加载失败 / 404 / 网络断开 / 登录过期 | — | 待画（一张「通用状态」画板） |
| 批量结果弹窗 | SecOps 任务记录可复用 | 待统一 |
| NoAccess | NoAccess | 已有，需加「需要的角色、管理员、申请权限」 |
