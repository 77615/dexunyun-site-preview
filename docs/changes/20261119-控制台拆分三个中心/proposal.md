# 控制台拆分三个中心

## 为什么
顶部 tab 原来是「总览 / 我的产品 / 费用 / 企业」，把功能分区当成了总览的视角。只从顶栏进入的工单、消息页面上也挂着这四个 tab，而且没有一个高亮，看起来像属于其中某一项（F1）。腾讯云首页的 tab 只是总览的不同视角，费用中心、账号中心是左菜单 + 右内容的独立中心。

## 改成什么
- 顶部 tab 只留视角：总览、我的产品（含按资源、选购、权益转移等我的产品下的页面）。
- 费用中心（顶栏「费用」进入）：概览 / 订单 / 付款 / 收支明细 / 发票 / 合同。原二级分段改成左侧菜单。
- 企业中心（头像菜单进入）：企业信息 / 成员 / 角色权限 / 安全设置。
- 支持中心（顶栏「工单」「消息」进入）：我的工单 / 提交工单 / 消息 / 文档。消息原来顶栏名「消息中心」，并入支持中心。
- 中心页用产品控制台同款左侧菜单（可折叠，菜单头写中心名），页面背景纯灰，页头是当前菜单名，原问候语去掉。详情和流程页高亮所属菜单（如订单详情 → 订单，企业认证 → 企业信息，无权限页 → 付款）。面包屑「费用」「企业」改成「费用中心」「企业中心」。
- 卡片里的状态页签、模块分层、表格不变。

## 中心入口（F3）
- 总览、我的产品的页签行右侧：费用中心 · 企业中心 · 支持中心（腾讯云首页页签行右侧放常用入口的做法）。
- 头像菜单顶部三张入口卡，各带一句说明（订单 · 付款 · 发票 / 认证 · 成员 · 权限 / 工单 · 消息 · 文档）。
- 产品与服务面板的「管理中心」分组：控制台总览、我的产品、费用中心、企业中心、支持中心。
- 顶栏原有入口不变：「费用」下拉（底部改「进入费用中心」）、「工单」、「消息」。
- 中心左侧菜单头：中心名下方「‹ 返回控制台总览」；左上角 Logo 也回总览。

## 产品与服务弹窗（F4）
- 菜单按钮放在顶栏最左，Logo 在它右边。
- 弹窗左栏顶部是位置固定的常用入口：控制台总览、我的产品、安全中心、费用中心、企业中心、支持中心，带图标，所在中心高亮；下面是最近访问、我的收藏。
